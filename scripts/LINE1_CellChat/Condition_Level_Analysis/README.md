# Condition-level LINE-1 / CellChat analysis

## Overview

This directory contains the condition-level analysis used to evaluate the
relationship between locus-specific L1FLnI expression and CellChat-derived
intercellular communication metrics across retinal disease states.

This analysis is distinct from the donor-level LINE-1 / CellChat analysis
included elsewhere in this repository.

Three disease-state-specific CellChat networks were analyzed:

- Healthy Control
- Dry AMD
- Wet AMD

Each CellChat network was generated by pooling all cells belonging to the
corresponding disease state.

Therefore, the statistical unit in this analysis is the aggregated disease
condition rather than the individual donor.

---

## CellChat networks

The condition-level CellChat objects contained:

| Condition | Cells | Cell types | Significant LR interactions | Pathways |
|---|---:|---:|---:|---:|
| Healthy Control | 11,010 | 9 | 614 | 29 |
| Dry AMD | 8,633 | 9 | 1,317 | 47 |
| Wet AMD | 19,686 | 9 | 518 | 27 |

Two CellChat network metrics were used.

### Network density

Network density was calculated as:

    active directed edges / possible directed edges

With nine retinal major cell classes, the maximum number of directed
cell-cell combinations was 81, including autocrine interactions.

Observed values were:

| Condition | Active edges | Possible edges | Network density |
|---|---:|---:|---:|
| Healthy Control | 68 | 81 | 0.8395 |
| Dry AMD | 81 | 81 | 1.0000 |
| Wet AMD | 65 | 81 | 0.8025 |

### Total communication strength

Total communication strength was calculated as the sum of the CellChat
aggregated network weights:

    sum(CellChat@net$weight)

Observed values were:

| Condition | Total communication strength |
|---|---:|
| Healthy Control | 18.91069 |
| Dry AMD | 38.32379 |
| Wet AMD | 13.83681 |

Dry AMD therefore showed the highest aggregated network density and total
communication strength in this condition-level CellChat analysis.

## Global locus-specific L1FLnI expression

Twelve candidate L1FLnI loci identified in the previous differential
transposable-element analysis were evaluated.

For each locus, expression was quantified across all retinal cells belonging
to each disease condition.

Two complementary measurements were calculated.

### Mean expression

Mean normalized expression represents the average normalized expression of
a locus across all cells from a disease condition.

For condition c and locus l:

    MeanExpression(c,l) = mean normalized expression across all cells in c

This measurement captures the overall abundance of locus-specific
expression.

### Detection rate

Detection rate represents the fraction of cells in which the locus had
detectable expression:

    DetectionRate(c,l) =
        number of cells with expression > 0 /
        total number of cells in the condition

This measurement captures how broadly locus activity is distributed across
the retinal cell population.

---

## Condition-level association analysis

For each of the 12 L1FLnI loci, four relationships were examined:

1. Mean expression vs Network density
2. Detection rate vs Network density
3. Mean expression vs Total communication strength
4. Detection rate vs Total communication strength

Each relationship contains three observations:

    Healthy Control
    Dry AMD
    Wet AMD

Pearson correlation coefficients and R-squared values are calculated to
describe the direction and magnitude of the condition-level relationship.

Because only three aggregated disease conditions are available, these
correlations are considered descriptive and should not be interpreted as
donor-level inferential evidence.

The donor-level analysis, in which individual donors represent independent
observations, should be used for biological inference regarding associations
between LINE-1 activity and intercellular communication.

## Scripts

### `LINE1_Locus_ConditionLevel.R`

Calculates global locus-specific L1FLnI expression for each disease
condition.

For each candidate locus and condition, the script calculates:

- number of cells
- mean normalized expression
- detection rate

These measurements are then integrated with the condition-level CellChat
network density and total communication strength.

Expected output:

    12 loci × 3 conditions = 36 rows

---

### `Figure_LINE1_ConditionLevel_Correlations.R`

Generates one four-panel figure for each candidate L1FLnI locus.

Panels:

    A. Mean expression vs Network density
    B. Detection rate vs Network density
    C. Mean expression vs Total communication strength
    D. Detection rate vs Total communication strength

Healthy Control, Dry AMD, and Wet AMD are displayed as separate points.

Pearson r and R-squared are reported as descriptive measures.

## Interpretation

This analysis evaluates whether disease-state differences in global
locus-specific LINE-1 activity parallel changes in the architecture and
strength of the aggregated retinal communication network.

It complements, but does not replace, the donor-level analysis.

The two analyses address different biological levels:

    Donor-level analysis:
        variation among individual biological samples

    Condition-level analysis:
        global communication architecture after pooling cells within
        each disease state

Condition-level correlations should therefore be interpreted as descriptive
patterns across disease states rather than independent biological
replicates.
